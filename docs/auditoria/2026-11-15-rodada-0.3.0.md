# Rodada 0.3.0: o que saiu das pendências e o que falta

Continua [`2026-11-11-pendencias.md`](2026-11-11-pendencias.md), que fica como registro. Esta rodada foi feita em
nove frentes paralelas (canal, entrada e idiomas, enquadramento, editor de cortes, fila e SSE, painel, publicação,
agente e MCP, repositório), integradas num branch só e conferidas juntas. O que mudou para quem usa está no
[`CHANGELOG.md`](../../CHANGELOG.md).

cuBLAS derrubava o `transcrever` no modo `auto`, e o `musicas baixar` não baixava nada num clone novo.

## 4. Antes de usar a 0.3.0 no canal

1. `git pull`, depois `scripts\instalar.ps1` (reaproveita o `.venv` e só atualiza).
2. `clipline doctor`: o item **músicas** diz se faltam `.mp3`; **GPU da transcrição** diz se o `transcrever` vai
   para a GPU ou para a CPU; **tarefa de publicação** avisa se a tarefa é a antiga.
3. Se o `doctor` avisar da tarefa antiga, o dono reinstala com `publicar instalar-tarefa --confirmar` para o log
   passar a girar.
4. Num corte já feito, em cópia: trocar o trecho pelo painel e conferir o corte montado de novo.
5. Ligar `[enquadramento]` num episódio e decidir se fica.
